# Actividad-6.-Refactorizaci-n
Artefacto a refactorizar: Función monolítica calc_EST que combina la depuración de datos erróneos con el cálculo estadístico de varianza; requiere separar la limpieza del cálculo y eliminar variables tipo aaa, x1 aplicando PEP 8.

En donde el estudiante aplicará principios de modularidad, convenciones de codificación formal y separación de responsabilidades sobre un módulo de código monolítico preexistente. Utilizará la IA como consultor técnico para obtener la guía procedimental y el pseudocódigo de reestructuración, encargándose el alumno de reescribir, modularizar y validar manualmente el código en su IDE local.
